Power calculation, cable resistance and limits

Equipment load: use a matching manufacturer current-versus-voltage curve when available. Input watts use I = W ÷ (V × PF); VA uses I = VA ÷ V. Known current holds the entered amperage constant. Watts with PF = 1 is a visible unity-PF estimate.

Shared cable: downstream currents add on each upstream section. Voltage drop uses section current × series loop resistance; cable/contact loss uses I² × R. The solver recalculates equipment current as voltage changes.

Resistance: published center-conductor plus shield values are referenced to 68°F / 20°C. Built-in values use your power cable temperature and coefficient. Custom loop resistance is used as entered at its actual temperature. Extra contact resistance is also used as entered. Parallel returns and waveform differences are not modeled.

Missing data: unknown cable or equipment data leaves results unavailable. A source curve is never extrapolated outside its published voltage range. A failed voltage solution is reported instead of displaying a partial total.

Parts, loss tables and sources

Match the complete model, housing and installed faceplate. An upgrade faceplate is a different selection from its original legacy part.

How the calculation works

At a tap: tap-port level = incoming level − preceding cable loss − tap loss. The next trunk section uses through loss, not tap-port loss.

Branches: select the actual upstream splitter/coupler port in “Fed from.” Deleting a parent leaves a warning; the route is never silently reconnected.

Normalized sweep: output minus source, then zeroed at the reference frequency: −[path loss(f) − path loss(reference)]. Launch tilt is removed. Use absolute mode for expected meter levels.

Estimates: cable loss uses published dB/100 ft points interpolated in √frequency and a 0.1%/°F correction from 68°F. Passive point tables interpolate linearly in MHz; band tables use their stated band, with the upper band chosen at shared boundaries.

Limits: no passive/cable extrapolation outside published data. Maximum-point interpolation is not a guaranteed maximum between points. Planning mode falls back to maximum values where typical values are not published and labels that basis.

Field additions: plugin EQs, pads, drop cable, connectors and other losses must be added explicitly using cable-only/custom rows. The model does not predict reflections, suck-outs, ingress, MER, compression or active alignment.
