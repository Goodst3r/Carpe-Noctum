# Fresh rebuild integration contract

User-approved Q&A overrides historical instructions. No legacy job compatibility. No Grok. Codex implements; Claude reviews separately. All new source is ES modules in app/*.mjs. Tests use node:test in tests/*.test.mjs. Do not edit other agents' files, build scripts, package files, or generated outputs.

## State
`job = {schema:1,id,name,split:'low'|'high',nodes:[],edges:[],portSweeps:{},map:null,placements:{}}`.
Node: `{id,name,tag,kind:'node'|'active'|'passive'|'eol',modelId,settings:{mode,director,...},map?:{page,x,y,symbolId,confirmed},readings?:{[port]:{samples:[[MHz,dBmV]],...}}}`. Map positions x/y are fractions of displayed page. Edge: `{id,from,port,to,cableId,lengthFt,confirmed}`. Each node has one physical upstream feed; loops/multiple feeds unresolved. Port IDs are `main`,`aux1`,`aux2` for HGD, `main` for LE/passives, node physical ports `1`..`4` etc. Node sweep key `${nodeId}::${port}`. Import never assumes schedule values are measurements.

## Modules / owners
- rf.mjs and catalog.mjs (Astra): exports `evaluateRoute(job)` -> `{frequencies,stations:{[id]:{input:[[f,number|null]],outputs:{[port]:[[f,number|null]]},targets:{[port]:[[f,number|null]]},gainStatus,shortfall,recommendation,issues:[]}},issues:[]}`. Node port samples set targets; only those frequencies evaluated. Also exports `recommendParts(modelId,inputSamples,targetSamples,settings={})`, `designLevel(split,f)`. catalog exports `EQUIPMENT` dictionary values `{id,label,kind,ports,band,...}`, `CABLES` dictionary values `{id,label,...}`. Gain recommendations must be sourced/estimated explicitly. Missing is null, never zero.
- graph.mjs, io.mjs, store.mjs (GPT6 Sol): graph exports `traceRoute(job,{startId,port,mode:'all'|'destinations',destinations:[]})` -> `{nodeIds,edgeIds,issues}` and `validateGraph(job)` -> issue strings. io exports async `parseONX(bytes,options)` -> `{samples,rawSamples,metadata,correction}` with options `{connection:'tp'|'direct',testPointLoss:20}`; `replaceSweep(job,nodeId,port,sweep)` pure returns updated job. store exports `createJob(split)` and `saveJob(job)`, `listJobs()`, `loadJob(id)`, `deleteJob(id)`; storage is new namespace. New job includes source node id `node`, modelId gs7k / vecima, no sweeps. Also new backup export/import with verified original attachment storage where feasible. Dependencies fflate available via root install.
- maps.mjs (Sol): exports async `importMap(bytes,{onProgress}={})` -> `{sha256,pages,nodes,edges,issues}`, async `renderPage(bytes,pageNumber,canvas)`, async `exportMap(bytes,job,evaluation)` -> PDF bytes, `extractSchedules(pages)` pure. Parsed page shape documented in own module tests. PDF libraries loaded via embedded assets (root handles HTML): globals pdfjsLib, PDFLib; pdfjsWorker script inline. Tesseract bundled as optional local assets. No app UI in module. No private files committed.
- ui.mjs + style.css (Terra): exports `mountApp(element)`; imports modules above. Full interactive app. Keep Tools/Route tabs only. Root entry calls mountApp. Map original bytes session-local; job.map stores hash/geometry. Show importer draft candidates for confirmation, map selection/editor, all/destination tracing, HGD side-by-side, one sweep trace selector; job library in Route. Import editing and storage invoke shared state. Async picker/imports guarded against job changes. Do not use old app globals.
