# ACI pilot guide transcription — 1.7 Alpha build 21

Source: Spencer Williams supplied photos of ACI's **iPhone / iPad Pilot Channel Code Guide, Revision A**, cover and table pages 2–5 of 6, in this conversation on November 10, 2026. No publication date or exact supported app/firmware version is visible in the supplied pages. The adjacent scanned material identifies DSIM-SG Installation Guide Rev E; it does not establish the applicability of these codes to every installed module.

The application includes 86 literal source rows: channels 52–94 and 100–142, with separate IRC and digital frequencies/codes. Two independent reviews checked all rows against the supplied images. The reference is not an algorithm or universal supervisor password generator. Values for channels 95–99, 303 MHz, CW or OFDM PLC are not supplied.

Spot checks: digital 465 MHz/channel64 → `EC<A`; digital609MHz/channel88 → `GG<A`; digital711MHz/channel110 → `@@?<A`; IRC709.25MHz/channel110 → `@@?<@`. Punctuation and case are preserved.

Channel100 is printed as `HD<@` (IRC649.25MHz) and `HD<A` (digital651MHz), unlike the apparent numbering pattern of nearby rows. The application retains the printed values, marks the source exception, and disables copying. No alternate code is inferred. LED blink-column anomalies are outside the lookup data and were not silently corrected or included.

Reference codes come from the supplied document. They are not user-entered secret credentials. The application never communicates with or programs DSIM hardware, and selecting a reference code does not mark a pilot/key verified or establish RF acceptance. Compatibility and actual operation remain physical-device checks.

The later app guide's direction to obtain the approved pilot key from a manager/supervisor is retained as operational context. Earlier 'no code table verified' research conclusions are superseded for the photographed rows; they remain unresolved for unsupported models, firmware or pilots.
