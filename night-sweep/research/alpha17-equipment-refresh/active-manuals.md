Reviewed November 10, 2026. All 23 current field active profiles are mapped. The two UBT profiles are excluded from current workflows at the user's direction. Historical manufacturer manuals are labeled as mirrors; a matching public edition is not a promise that it is the latest manufacturer-issued revision. No plant equipment, instrument firmware or physical phone was tested in this research.

The OEM steps begin with identity, approved design frequencies/levels/loading, valid input, and approximately one hour warm-up. Manual backoff is set before output pad/EQ adjustment; thermal setup uses its separate S1 branch. Raw -20 dB test-point readings receive +20 dB once, only when the meter has not already applied compensation. SA and LE temperature/reference-frequency charts differ; neither is the DSIM chart. HGD/LGD auxiliary points are after the signal director, while the SA AGC pad uses the MAIN pilot reference. The manuals require settling between switch changes but give no fixed timer.

The historical conventional OEM guides describe an analog video pilot. An exact OEM QAM detector offset/application bulletin was not recovered. The -6 dB QAM/analog relationship in distortion-loading tables is not applied as an AGC correction. Technicians must match the actual detector, pilot frequency/type and level convention. ACI DSIM remains a separate workflow owned by its module-specific reference.

For AOI, the prior original SA PDF URL returned HTTP 404 during a live fetch. The replacement link is a working historical mirror identified by V02102025. The current manufacturer page provides guides by request, so the latest issued firmware/manual combination still needs manufacturer confirmation. The roughly 30-second spectrum acquisition is a scan time, not an AGC settling delay. The AOI upstream Manual section specifies ONX-630 DOCSIS Expert; it does not replace the operator's separate 204/258 MHz XPERTrak return-sweep workflow.

Firecrawl and Parallel both worked for this refresh. Firecrawl fetched the current AOI page, matching SA manual pages and eight exact manufacturer datasheet PDFs. The LE mirror returned only skeletal text to Firecrawl; an independent indexed reader recovered the complete manufacturer-authored body and page references. Parallel found current indexed manufacturer references but no exact public Quantum18 LE/BA I&O or OEM QAM level-offset bulletin. Redirects and missing pages are recorded in `active-source-checks.json`; no purchase or upgrade was made.

`setup-manuals.json` adds distinct control types and complete ordered `procedureModes`. Each refreshed procedure has a new record ID so previously checked steps cannot silently acquire different directions. Validation checked all current active IDs, exact mapping IDs, HTTPS URLs, mode identity, and absence of UBT in current active workflow records. Root owns integrated UI, browser and release validation. The retained datasheet specifications remain reference configurations, not operating targets or arbitrary-frequency gain curves.
