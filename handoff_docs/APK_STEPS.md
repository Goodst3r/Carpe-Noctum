## 1. Before installing — back up

1. Open the installed **Carpe Noctum 2.0 Preview build 3** (code 27).
2. For every important job, export the complete project (with original attachments) and save it outside the app (Files, Drive or a computer).
3. Open one export to confirm it saved. Note how many jobs you have and pick one job with readings and attachments to compare after the update.

A run-sheet CSV or PDF is not a full backup.

## 2. Install over the existing app

1. Copy the APK to the phone and check its SHA-256 matches above if you can.
2. Open it from Files and choose **Update**. Allow the installer only as your device policy permits.
3. **Do not uninstall** and do not clear app data. If Android says the package conflicts or the signature does not match, stop and report the exact message. Do not work around it.
4. Confirm the launcher shows **Carpe Noctum 2.0 Preview build 4**.

## 3. Saved data

1. Open the app. Confirm the job count matches step 1.
2. Open the job you noted: readings, notes and original attachments are present and open.
3. Export it again and confirm the export works.

## 4. Route & sweep and map import (synthetic map only)

1. Create a practice job. Import a synthetic or practice map PDF/image (not HA0005 for this step).
2. Confirm the **original markings preview image appears** next to the review list. (This is the item fixed for Android in this build.)
3. Confirm unclear rows show a review reason and that NAME, TAG and model are separate. Choose a launch/port, build the draft, and edit one row.
4. Open an active row: check expected levels and the gain result; select another output leg and confirm it does not reuse the main leg's gain.
5. Enter Before and After input/output readings and a few pad/EQ values; leave some blank. Save, leave the job, reopen it: values are intact and still editable.
6. Export the job and import it back; values are intact.

## 5. Phone behavior

1. Turn on airplane mode, force-stop the app, and cold-open it. Note roughly how long it takes to show the job list. Open a job and a calculator.
2. Switch to another app and back; lock and unlock while a job is open. Nothing is lost.
3. Open a document picker (import), cancel it, then use it; save an export with the save picker; share a run sheet; open print and cancel.
4. Rotate if you use landscape. Press Back from a few screens.
