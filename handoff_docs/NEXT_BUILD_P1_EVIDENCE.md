## Changes and review points

- Evidence headings render without creating closed preview charts or tables. Opening a preview materializes the current job's data; an open preview survives a redraw, while a job change does not carry it over. Print preparation materializes previews. Original evidence bytes and saved-job format are unchanged by this work.
- Sweep Due saves text on input and immediately validates it; the old list and counts are hidden and marked stale until change, Enter, refresh, or resume commits the draft. A committed draft does not get redundantly committed on blur, which preserves keyboard pagination focus. Invalid and blank intervals do not become green reminders. The existing named-job renderer now refreshes a visible tracker after imports, owner changes and saved-library changes, while same-owner redraws preserve an uncommitted stale draft. A focused interval control receives the new owner's value on replacement.
- Full-app startup now installs EvidenceUI after the final base print hook exists, preserving synchronous preview materialization when `NightSweep.preparePrint()` is called directly. This corrects a demonstrated overwritten hook; an actual Android print omission was not reproduced.
- No calculator, storage-format, storage-key, Android package, or signing-key changes are included. P2/P3 were not implemented in this correction. No deployment, signed APK, or physical-phone acceptance is claimed.
