# NightSweep 1.8 Alpha build 2 — verification

The final frozen application passed **1,066 checks across 57 automated suites** and **322 rendered Chromium checks**. The real Android APK was compiled, signed with the original Preview key and independently checked for its package/version, certificate, signatures, alignment and embedded application bytes. Read `validation.json` for exact hashes and machine-readable scope.

**Native runtime remains unverified.** An Android 15 software emulator accepted the original Build 22 APK and the compatible Build 24 update, retaining the package UID and a generic app-private fixture. Both versions then hit the same stock WebView renderer SIGTRAP. Native screens, picker/save/share/print and retention of actual saved jobs/original evidence were not verified. No app Java/JavaScript cause was established. No physical Android or iPhone was tested.

Public `HFC.run` counters exclude internal closure work; the report explicitly qualifies this. These are executor observations, not phone-performance guarantees.
