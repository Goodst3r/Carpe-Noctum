Start connected. Use Safari and the Home Screen icon. The Android .apk file does not install on an iPhone. This version is a web app; it does not require an App Store download.

1. Add the Home Screen icon

Keep an internet connection for installation and the first launch. Safari menu names and placement vary by iOS version.

  1. Open the app address in Safari

    Use the button above or type the displayed address. If a message opens the site inside another app, open that address in Safari.

  2. Choose Share → Add to Home Screen

    Open Safari's Share menu and find Add to Home Screen. You may need to scroll down in the share sheet. If your iPhone shows Open as Web App, turn it on.

  3. Tap Add, then open NightSweep

    Keep the name NightSweep. Return to the Home Screen and tap the new icon while you are still online. Confirm 1.8 Alpha build 2 and the Home tab.

  4. Wait for the offline status

    Stay in the app until Home shows Ready for offline use. Seeing the page alone does not mean the offline copy has finished installing.

Already entered a job in Safari? Export it there before switching to the Home Screen app. Safari and the installed app may have separate job storage. Import your project file in the app you will use.

Use one NightSweep window at a time. Close other NightSweep tabs before continuing a job; concurrent windows can overwrite newer local edits with an older copy.

2. Check it before going offline

Do this on your own phone before relying on NightSweep at a work location.

  1. Use Home → Open complete training job for the check. Export any real working job first; opening training keeps its local copy in named jobs, but an exported file is the separate backup.
  2. After Ready for offline use appears, turn on Airplane Mode and make sure Wi-Fi is off.
  3. Close and reopen NightSweep from the Home Screen icon. Open a calculator, enter a test value, and confirm that it works.
  4. Reconnect when finished. If the app does not reopen offline, open that icon online, wait for the ready status, then repeat the check.

Available offline

The cached app, its calculators, and the job data and evidence available in that app's local storage.

Needs a connection

First setup, app updates, manufacturer links, and any files that still need to download from a cloud drive.

Home's Protect local storage button requests browser storage protection. The browser decides whether to grant it. It cannot guarantee retention and does not replace project backups.

Learn every tab with the included example. Home's Open complete training job starts the Cedar Lane practice job and a 21-step guide. Choose Open step, try the controls, then mark Reviewed. A route, two amplifiers, power plan, readings, five synthetic CSVs, and an original-only diagram are included offline. All are teaching data, not field measurements. Reset training job preserves your practice copy before restoring the starting exercise. Reopen your real job under Job → Details when you finish.

3. Save a backup outside the app

Autosave and named jobs help you continue work. An exported project is the file you can restore or move to another phone.

  1. Review the current job

    Check its name, route, readings, and attachments. Keep only one NightSweep window open.

  2. Choose Files → Save project

    You can also choose Export backup on Home. If Your file is ready appears, tap Save/share file, then Save to Files where offered. Or choose Download file. Finish the phone's save action; a prepared export is not yet a confirmed backup.

  3. Find the project in Files

    Look for NightSweep_1.8_Alpha_build_2_Project.json in Downloads or the destination you chose. Your settings may put downloads in On My iPhone or iCloud Drive. Repeated downloads may have numbered names.

  4. Keep a copy for each job

    Use recognizable job/date names or folders. To restore or transfer a job, choose Files → Open project in NightSweep and select the exported .json file. Check the imported route and evidence. To review the separate ONX-630 reference job, open its project JSON here and choose Job → ONX files.

No automatic job sync. Each phone and app/browser keeps its own data. The website delivers the software; it does not keep a server backup of your jobs or original evidence files. Storage may be removed by device settings or storage management. Export before updates, clearing website data, or removing the icon.

A run-sheet CSV, PDF, screenshot, or meter photograph is not a complete project backup. Original meter files travel with a full project export within the app's export limits.

Updating the web app

  1. Export each job you need and close other NightSweep windows.
  2. Connect to the internet. On Home, choose Check for updates.
  3. If an update is offered, choose Install update, then Reload app when it becomes available.
  4. Verify the version, a saved job, and Ready for offline use. Repeat the offline check before field use.

Do not delete the icon or clear website data as the first fix for an update problem while unexported work remains.

If something does not look right

I cannot find Add to Home Screen.

Open the actual NightSweep address in Safari, then review the Share menu. A managed company phone may restrict web apps; use the employer-approved process or ask the device administrator.

The app is blank or will not open without internet.

Reconnect and open NightSweep from the installed Home Screen icon. Wait for Ready for offline use, then retry the offline check. Confirm that you are opening the installed app rather than a different browser tab.

My job appears in Safari but not in the icon app.

The storage may be separate. Export the project from Safari, then use Files → Open project in the Home Screen app. Keep the original and the export until you have checked the imported job.

I exported a backup but cannot find it.

Choose Save/share file or Download file if the prepared-file panel appears. Complete the phone's save action and check Files, Downloads, and the selected destination. The app's prepared message is not proof that the file exists. Export again if needed and verify the resulting file.

A meter photo has no measurement preview.

Photos are evidence attachments. NightSweep does not read their displayed numbers into the calculators or decode native ONX measurements from a photo. Enter measurements with their units, frequency, and remaining test-point correction.

Can I move a job from the Android app?

Yes: export its full project with Files → Save project, transfer that JSON file using an approved method, and open it with Files → Open project in the iPhone app. Check the route, records, and original attachments. The phones do not share jobs automatically.

Alpha status: physical iPhone installation, file-picker, print, storage, and field behavior have not been verified on your device. Use the checks in this guide. The main README covers every task tab and calculation limit.

Start at the actual launch output

In Route → Setup, choose Node output, Amplifier / LE output, or Manual / other output. Select the exact equipment and port, then enter actual launch levels and only the remaining test-point correction.

Choose Source setup & manual, or Route → Equipment setup, then continue to cable route, sweep, readings and evidence. Source selection does not automatically change your levels. Export a project before updating and verify saved work afterward.
