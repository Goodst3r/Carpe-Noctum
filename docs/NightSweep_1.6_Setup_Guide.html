LEGACY

42/54 MHz · Forward and return sweepless

Live-service workflow for the ONX-630: forward Sweepless Sweep and DOCSIS Reverse Sweepless Sweep. Menu labels follow the VIAVI v5.5 guide; installed firmware may differ. All levels and acceptance limits come from the local design.

  1. Identify the 42 MHz system

    Record node, leg, station, exact amplifier model and installed 42/54 MHz diplex configuration. Confirm the ONX has the required reverse-sweepless option and a compatible DOCSIS RF module.

    Enter the actual downstream operating band, upstream carrier coverage, approved reference location and design targets. Keep the 42 MHz job separate from the 204 MHz profile; do not inherit injection or receiver targets from another plant.

  2. Connect and configure forward sweepless

    Open CATV Network → Sweepless Sweep. Stop → Configure → Configure Test Point. Copy a locked template, name it for the connection, enter the verified forward correction, then Done/Start. These templates apply to expert tests, not ordinary CATV tests.

    Record probe, lead, port and compensation already applied. Add each loss once. Confirm the installed split and actual downstream carriers; the split edge is not automatically a usable marker.

  3. Save the forward baseline

    At the approved reference location, verify design output level and tilt before saving. Use Stop → Configure → Save Test/Reference; give it a node/port/location name and select Set as Reference. Record the forward tilt compensation and its low/high anchor frequencies.

    Keep the original baseline. A trace normalized against itself can look flat while its absolute launch level is wrong.

  4. Check the forward cascade

    Compare each downstream station with the appropriate saved baseline, using consistent carrier selections and correction settings. Record actual levels, marker frequencies, tilt and response irregularities. Complete forward setup using the exact equipment procedure and design targets before return alignment.

    Attach the trace and downstream quality measurements. The downstream QAM/OFDM screens document forward performance; they cannot establish return gain or return acceptance.

  5. Start DOCSIS reverse sweepless

    Select Reverse Sweepless Sweep through Sweep Mode where offered. Stop → Configure: select the site DOCSIS Service Plan and correct test-point template, including separate forward and reverse compensation. Start and wait for DOCSIS Connected.

    This uses DOCSIS operation and adds no sweep pulses. It requires live service and measures occupied upstream spectrum only. If DOCSIS cannot connect, mark the return test incomplete and troubleshoot the connection; do not substitute a passing calculation.

  6. Set a consistent return display basis

    Record Ref BW and keep it consistent: Modem Default, 1.6 MHz or 6.4 MHz. Modem Default uses each SC-QAM channel bandwidth and 1.6 MHz for OFDMA. Changing between 1.6 and 6.4 MHz changes normalized power by 6 dB.

    Display → Sweep View Type offers Detailed or 1.6 MHz; this is a separate setting. Record actual tested channels, not just a nominal 5–42 MHz label.

  7. Establish and retain the return reference

    Verify the reference location against the approved design before saving. Absolute is the estimated adjusted response at the CMTS/RPHY; Referenced shows change from the saved location. Neither is automatically a direct RF reading at the node test point.

    Save a named reference with Set as Reference, or use Configure → Choose Reference. Record its node/port, service plan, Ref BW and corrections. Do not replace the baseline merely to remove an unfavorable trace.

  8. Balance the verified legacy amplifier cascade

    For the cited conventional GainMaker procedure, establish the reverse optical link first, then work from the node toward successive amplifiers and branches. Check the exact station manual before changing pads.

    The amplifier reverse output EQ controls received tilt; the reverse output pad controls level. More output pad reduces received level. Preserve design reverse input pads unless the applicable procedure calls for a temporary change, and restore them afterward. Node optical-drive settings have their own procedure.

  9. Evaluate each occupied segment

    Wait for DOCSIS results to settle after a change. Review referenced A/B levels and Min/Max Δ against the locally approved criteria. Negative referenced response indicates relative loss; positive indicates relative gain.

    Track absolute transmit/receive information as well as the referenced shape. Do not use a sweepless CMTS estimate as a CW receiver target in a pad calculator. Gaps outside active channels remain untested; further testing needs the operator-approved method.

  10. Verify, save and close out

    Save separate before/after traces and the unchanged baseline identity. Record equipment/port, settings changed, measured coverage, targets, correction basis, result time and unresolved faults. Check ingress and DOCSIS service performance as additional evidence.

    Use Measured / Incomplete / Needs review until the required evidence and operator limits are available. Mark unmeasured frequencies explicitly. Export the job with its original files for supervisor review.

HIGH SPLIT

204/258 MHz · Forward sweepless and XPERTrak return sweep

High-split workflow using forward Sweepless Sweep and active return sweep through the operator’s XPERTrak-supported deployment. NightSweep records and guides the work; it does not configure the ONX, RPD or XPERTrak.

  1. Identify the high-split path

    Record node/RPD identity, upstream port or segment, station/leg, exact amplifier and installed 204/258 MHz configuration. Confirm meter hardware, options and firmware support the required band and test mode.

    Enter the actual test limits and reference plane. A 204 MHz split does not define the sweep-plan endpoints, occupied channels or receiver target. Verify the route and return port paths independently of forward losses.

  2. Connect and configure forward sweepless

    Open CATV Network → Sweepless Sweep. Stop → Configure → Configure Test Point. Copy a locked template, name it for the connection, enter the verified forward correction, then Done/Start. These templates apply to expert tests, not ordinary CATV tests.

    Record probe, lead, port and compensation already applied. Add each loss once. Confirm the installed split and actual downstream carriers; the split edge is not automatically a usable marker.

  3. Save the forward baseline

    At the approved reference location, verify design output level and tilt before saving. Use Stop → Configure → Save Test/Reference; give it a node/port/location name and select Set as Reference. Record the forward tilt compensation and its low/high anchor frequencies.

    Keep the original baseline. A trace normalized against itself can look flat while its absolute launch level is wrong.

  4. Check the forward cascade

    Compare each downstream station with the appropriate saved baseline, using consistent carrier selections and correction settings. Record actual levels, marker frequencies, tilt and response irregularities. Complete forward setup using the exact equipment procedure and design targets before return alignment.

    Attach the trace and downstream quality measurements. The downstream QAM/OFDM screens document forward performance; they cannot establish return gain or return acceptance.

  5. Confirm XPERTrak sweep readiness

    Use the approved operator procedure to confirm the correct node/RPD upstream port, sweep-plan identity and enabled sweep service. For supported R-PHY deployments, the RPD provides the receiver and downstream telemetry, coordinated by XPERTrak RCI.

    Record the approved telemetry frequencies, user mode, sweep coverage and test levels. Exact portal controls vary by deployment; this guide does not supply guessed clicks. Field View spectrum monitoring is distinct from Reverse Sweep.

  6. Configure the meter for active return sweep

    Open Reverse Sweep. In Configure, match the operator’s telemetry and user-mode settings. Select the connection’s test-point template and correct single/dual-port arrangement; verify forward and reverse paths match that wiring.

    Confirm usable telemetry and a fresh response from the intended receiver before alignment. If absent, resolve node/port selection, enabled service, meter mode and physical connection before changing plant settings.

  7. Confirm injection and receiver conventions

    Keep desired network-plane injection, coupling/lead loss and raw generator output distinct. The ONX template combines Reverse Sweep Injection with Reverse TPC; do not add the same coupling loss again. Check the installed meter’s total output limit.

    Enter the receiver target with its exact RF/digital reference plane and measurement basis. Previously discussed 31 dBmV injection and −8 dBmV receive are unconfirmed site examples, not defaults. Sweeping through occupied OFDMA requires the operator’s approved plan and settings.

  8. Save the approved active-sweep reference

    At the approved baseline location, confirm absolute level and response meet the design. Save a named test/reference; retain node/port, telemetry, injection, correction and plan details. At later locations select the matching reference.

    Record both absolute and referenced evidence. Normalizing a trace does not prove correct optical/RPD drive or absolute gain. Keep the same comparison basis and identify any plan changes before interpreting differences.

  9. Apply the sequence for the exact amplifier

    Quantum18 SA HGD/HGBT: the cited AOI guide starts upstream alignment at the last amplifier after the cascade’s downstream setup is complete. For its Auto mode, use Upstream → Start Auto in the AOI interface, then review the completion result and Save/Revert decision. Continue according to that model’s procedure.

    This is distinct from manual GainMaker node-outward balancing. Do not apply SA auto-alignment instructions to LE, BA, another hardware revision or manual sweep adjustment without its matching procedure. Record how each station was aligned, then verify with return sweep.

  10. Verify the return path and investigate exceptions

    Compare fresh traces at the required stations/branches with the approved reference. Record level, tilt, response deviations and actual coverage. Use the exact amplifier’s gain/slope controls or pad/EQ procedure; do not infer settings from its forward gain specification.

    Use XPERTrak spectrum and DOCSIS quality checks to investigate ingress, intermittent noise or service issues that a flat sweep may miss. Preserve unresolved exceptions and their locations.

  11. Verify, save and close out

    Save separate before/after traces and the unchanged baseline identity. Record equipment/port, settings changed, measured coverage, targets, correction basis, result time and unresolved faults. Check ingress and DOCSIS service performance as additional evidence.

    Use Measured / Incomplete / Needs review until the required evidence and operator limits are available. Mark unmeasured frequencies explicitly. Export the job with its original files for supervisor review.
