Corrections made during this review

  1. Power-table initialization: a valid loaded operating point could previously be rejected because the initial source voltage lay above the table. Initialization now starts within table bounds; subsequent lookups and final results still prohibit extrapolation.
  2. Nonfinite power results: extreme inputs could produce infinite derived outputs. The reviewed power/DC calculations now return unavailable results for overflow.
  3. Malformed current tables and node inputs: table shapes are validated before calculation; node numeric inputs reject structured values, blanks and infinity.
  4. Measurement-record false-pass protection: overflowing corrected readings, tilt or target errors now invalidate the record instead of allowing a passing result.
  5. Measured gain and chart overflow: nonfinite subtraction results are suppressed. Charts do not draw infinite/NaN differences as valid response traces.
  6. Copied span slack: the next-tap shortcut now retains physical slack, keeping the copied span’s total length consistent.
  7. RF and TDR arithmetic: nonfinite intermediate loss, level and distance values are rejected. The reviewed zero-distance/extremely-small-velocity-factor case no longer returns a successful NaN location.
  8. Frequency grid and export labeling: numeric-string frequencies are normalized before deduplication; frequency exports now carry the1.6 version label.

Two injection conventions remain distinct

The guided setup’s physical budget uses total physical coupling and lead losses to compute raw generator output. The existing job-record helper retains its remaining-loss convention for a manual setting after compensation already applied elsewhere. Its labels identify that convention.

Neither result should be copied blindly into an ONX field. The ONX test-point template combines its Injection setting with reverse TPC. Record which convention is being used so the same correction is not counted twice.

What the results do not establish

Power planning uses scalar current magnitudes and resistive loop drops. It does not solve phase angles, harmonic currents, quasi-square-wave crest factor, transformer impedance/regulation, fuse coordination, standby batteries or utility-side input current. With PF below1, source VA is apparent power—not utility watts. Near voltage collapse, the bounded solver may report nonconvergence.

RF calculations rely on selected equipment, valid frequency ranges, measured or published values and entered correction settings. This review did not recertify all catalog data, ONX imports or physical service performance. A passing arithmetic example or flat referenced trace cannot replace correct absolute levels, complete coverage and field verification.
